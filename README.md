# Metodologia do Ganha Quanto

Descrição pública de como os números do https://ganhaquanto.com/ são produzidos. A versão completa e navegável está em https://ganhaquanto.com/metodologia/. Este repositório guarda o texto em formato versionado, para quem precisa citar ou conferir uma versão específica.

Licença do texto: CC BY 4.0. Os dados de origem seguem os termos de cada portal.

## Conteúdo

- [`fontes.md`](fontes.md): de onde vem cada dado.
- [`glossario-colunas.md`](glossario-colunas.md): o que significa cada coluna (bruta, líquida, indenizatórias, abate-teto).
- [`calculadoras.md`](calculadoras.md): fórmulas e base legal do salário líquido CLT, 13º, férias, hora extra, rescisão, PJ × CLT e teto do funcionalismo.
- [`CHANGELOG.md`](CHANGELOG.md): mudanças de método e de dados, com data.

## Como o número é produzido, em resumo

1. **Coleta mensal** dos dados oficiais publicados pelo órgão ou ministério.
2. **Recorte**: por órgão e cargo (serviço público) ou por ocupação (carteira assinada). A quantidade de registros (n) aparece junto de cada número.
3. **Estatística**: mediana, P10 e P90 e quantidade de registros (n).
4. **Calculadoras**: regras da legislação vigente, com a lei citada na página; resultados conferidos contra uma segunda implementação independente.
5. **Atualização** a cada novo mês publicado pela fonte; a data do dado aparece em cada página.

## Como citar

Ganha Quanto. *Título da página*. Dados: fonte oficial, período. https://ganhaquanto.com/… Acesso em AAAA-MM-DD.
